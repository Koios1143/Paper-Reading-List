# Paper Reading List

This is a vibe coding project generated by Gemini 3.

The objective of this project is to build a self-host service that maintain all papers (especially from arxiv and huggingface daily paper).

You can add paper with several tags, mark it read or unread, add to a folder, write some notes.

## Install

```bash
uv venv --python 3.11
uv pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Go to http://127.0.0.1:5000
